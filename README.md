# Predictive Credit Risk Modeling

## Project Overview
Built a machine learning model to predict customer credit default risk using credit bureau and repayment behavior data.

## Dataset
- 51,336 customer records
- 87 features
- Internal banking + external CIBIL data

## Workflow
- Data Loading
- Data Merging
- Data Cleaning
- Missing Value Handling
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Model Training
- Model Evaluation

## Feature Engineering
Created custom risk indicators:
- Delinquency Ratio
- Enquiry Intensity

## Machine Learning Models
- Logistic Regression
- Random Forest Classifier

## Evaluation Metrics
- Confusion Matrix
- Precision
- Recall
- F1 Score
- ROC AUC

## Key Insights
- Credit Score is the strongest predictor of default.
- Recent delinquencies and enquiries significantly impact risk.
- Feature engineering improved model performance.
- The model can support loan approval and credit risk assessment.
